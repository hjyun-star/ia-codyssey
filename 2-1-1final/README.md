# 나만의 프롬프트 관리 프로그램

## 소개
GenAI 활용 과정에서 쌓인 프롬프트를 카테고리별로 관리하고, 키워드로 검색하며,
즐겨찾기로 빠르게 찾아볼 수 있는 콘솔 기반 Python 프로그램입니다.

## 실행 방법
```bash
python main.py
```
(Python 3.10 이상 필요)

## 기능 목록
1. **프롬프트 추가** – 제목, 내용, 카테고리를 입력해 새 프롬프트 등록
2. **프롬프트 목록** – 등록된 모든 프롬프트를 번호·카테고리·즐겨찾기 여부와 함께 출력
3. **카테고리별 조회** – 선택한 카테고리에 해당하는 프롬프트만 조회
4. **프롬프트 검색** – 제목/내용에 포함된 키워드로 검색
5. **프롬프트 상세 보기** – 프롬프트 번호로 전체 내용 확인
6. **즐겨찾기 관리** – 프롬프트를 즐겨찾기에 추가/해제
7. **즐겨찾기 목록** – 즐겨찾기한 프롬프트만 모아보기

## 프롬프트 카테고리
- 텍스트 생성
- 이미지 생성
- 영상 생성
- 페르소나
- 자동화
- 기타

## 기본 등록 데이터
이전 미션에서 작성한 프롬프트 3개(블로그 글 작성 도우미, 제품 썸네일 생성,
IT 컨설턴트 페르소나)가 프로그램 실행 시 기본으로 등록됩니다.
